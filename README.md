## 📦 Build APK

This project uses GitHub Actions to build the Android APK.

### Build Instructions

1. Open the GitHub repository.
2. Go to Actions.
3. Select Build APK.
4. Click Run workflow.
5. Wait until the build succeeds.
6. Download the APK from Artifacts.
